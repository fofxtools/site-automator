# Pageview Statistics Web Viewer

PHP-based web interface for viewing aggregated pageview statistics.

## Files

- **`pageview-tracking/php/index.php`** - Date list view with summary statistics
- **`pageview-tracking/php/day.php`** - Detailed daily view with domain filtering
- **`pageview-tracking/php/views.php`** - Individual pageview viewer with pagination

## Production Deployment

### Install htpasswd utility

```bash
sudo apt-get install apache2-utils
```

### Create password file

```bash
sudo htpasswd -c /etc/nginx/.htpasswd stats
# Enter password when prompted
```

### Configure Nginx

Edit `/var/www/{domain}/conf/nginx/locations.conf` (subsitute `{domain}` with your domain):

```nginx
location /stats {
    auth_basic "Statistics Login";
    auth_basic_user_file /etc/nginx/.htpasswd;

    root /var/www/{domain}/htdocs;
    index index.php;

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/var/run/php/php83-fpm.sock;
    }
}
```

**Note:** Adjust `php83-fpm.sock` to match your PHP version. Check with: `ls /var/run/php/`

### Reload Nginx

```bash
sudo nginx -t
sudo systemctl reload nginx
```

### Upload files

Substitute `{server}` with the server IP address and `{domain}` with the domain:

```bash
rsync -avz pageview-tracking/php/{index.php,day.php,views.php} {server-alias}:/var/www/{domain}/htdocs/stats/
```

Visit: https://{domain}/stats/

**To logout:** Visit `https://logout@{domain}/stats/` to clear saved credentials.

### Configure open_basedir

This message indicates an open_basedir restrictions issue: `Data directory not found: /var/lib/pageview-tracking/agg/daily`

This is solved by editing these two files:

/etc/php/8.3/fpm/pool.d/www.conf
/etc/php/8.3/fpm/pool.d/www-two.conf

Edit `php_admin_value[open_basedir] =` to append `:/var/lib/pageview-tracking`. Then restart services:

sudo systemctl restart php8.3-fpm
sudo systemctl reload nginx

Both files must be edited. Otherwise, an error will occur on every other page refresh. This is because PHP-FPM uses multiple pools for load balancing.

## Local Development

```bash
# Create symlinks
sudo mkdir -p /var/www/stats
ln -s /home/$USER/projects/site-automator/pageview-tracking/php/index.php /var/www/stats/index.php
ln -s /home/$USER/projects/site-automator/pageview-tracking/php/day.php /var/www/stats/day.php
ln -s /home/$USER/projects/site-automator/pageview-tracking/php/views.php /var/www/stats/views.php

# Start dev server
cd /var/www/stats
php -S localhost:8080
```

Visit: http://localhost:8080/

## Data Source

Reads aggregated JSON files from `/var/lib/pageview-tracking/agg/daily/{date}.json`

Generated by `pageview-tracking/python/process_daily_logs.py`

## Features

**index.php:**
- Lists all dates (newest first)
- Click date to view details
- 19 columns with weighted averages across all domains

**day.php:**
- Detailed view for single date
- TOTALS row at top (recalculates when filtering)
- Domain filter dropdown
- Homepage vs Internal page breakdown
- View All Pageviews link to views.php for that date

**views.php:**
- Individual pageview records (raw data, not aggregated)
- Accessible from day.php (click domain name or "View All Pageviews" link)
- Pagination: 100 pageviews per page
- Filter by domain or view all domains
- Shows: Time, URL, Referrer, IP, User Agent, Language, Timezone, Viewport, Performance metrics

## Columns (19 total)

**Pageviews:**
- Pageviews, w/ Metrics

**Bot Signals:**
- GB UA (Googlebot User Agent)
- GB IP (Googlebot IP)
- G IP (Google IP - any)
- BB UA (Bingbot User Agent)
- BB IP (Bingbot IP)
- M IP (Microsoft IP - any)

**Performance Metrics (ms):**
- TTFB: Avg, Median, P95 (Time to First Byte)
- DCL: Avg, Median, P95 (DOM Content Loaded)
- Load: Avg, Median, P95 (Load Event End)

**Notes:**
- Timezone: UTC
- TOTALS row: Median/P95 are weighted approximations (marked with *)
